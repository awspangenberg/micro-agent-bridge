Make your Micro a task board

Each layer's six keys follow your pinned Codex and Claude tasks and light up with what they're doing. Press a key to jump to its task. Setup takes about two minutes.

    Connect your Micro

    Use one connection, either the cable or Bluetooth. If both are active, the bridge can't tell which one to use.

    Plug the Micro into this PC with its cable. Windows sets it up automatically.

    Put the Micro in pairing mode, following Work Louder's instructions for your board. Then add it in Windows under Bluetooth & devices → Add device → Bluetooth.

    A Micro remembers several Bluetooth channels. Pair on the channel you'll keep using; switching channels later makes the bridge see a different device.

      Choose how it runs

      You can change these later from the bridge's icon in the notification area.

      • Start with WindowsRuns quietly in the notification area after you sign in.
      • Alert me when a task needs meA Windows notification when a pinned task waits for your approval or an answer.
      • Detailed Claude statusAdds status hooks to Claude Code so keys can show planning, tests, edits and approvals. They record only the state of tasks pinned to your Micro, never prompts or code.
